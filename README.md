# DK Pokémon Open World RPG

Game nhập vai pixel-art tiếng Việt, ưu tiên điện thoại màn hình ngang.

## Chạy thử
Mở index.html bằng trình duyệt có Internet (Phaser 3 tải từ jsDelivr). Để bật GitHub Pages: Settings → Pages → Deploy from a branch → main / root.

## Bản dựng đầu tiên
- Bản đồ Kanto thử nghiệm: thị trấn, đường đất, bãi cỏ và hồ.
- Điều khiển bằng phím mũi tên/WASD hoặc nút cảm ứng.
- Chọn một trong ba sinh vật khởi đầu nguyên bản của bản thử nghiệm.
- Gặp Pokémon hoang dã, chiến đấu, dùng kỹ năng và thử bắt.
- Tăng cấp, nhận vàng và lưu cục bộ bằng localStorage.

## Lộ trình
1. Nhiều khu vực, va chạm địa hình, NPC và hội thoại.
2. Pokédex, đội hình sáu thành viên, túi đồ và trung tâm hồi phục.
3. Nhiệm vụ theo chương, Gym/Boss và tiến hóa.
4. Âm thanh, sprite-sheet hoạt ảnh, tối ưu cảm ứng.
5. Đóng gói Android APK và kiểm thử trên thiết bị thật.

Đây là bản thử nghiệm có gameplay cơ bản, chưa phải game hoàn chỉnh. Chưa tích hợp hình ảnh Pokémon chính thức hoặc APK.
